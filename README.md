# AI-screen translate

原理讲解：特定操作后截取屏幕，DS读取图中文字并根据上下文给出翻译内容，程序将外文替换为中文

具体实行：软件exe形式，参考加速器UI，用户可调整字体/自己的AI模型。运行时自动隐藏任务栏，参考桌宠，运行后根据设置表现为悬浮球/键位模式
   
    悬浮球模式：出现类似360悬浮球，单击左键翻译，长按左键拖动，右键调出控制台，可调整语言/关闭翻译/呼出主面板
    键位模式：默认ctrl + F12进行翻译，alt + ctrl + F12呼出控制台。可自主调整（无视快捷键设置限制，就可以按一下w就翻译，误触是用户自己的事）

具体翻译步骤：主面板调整全屏/框选模式，框选参考各截图软件。读出文字内容，分出ABC几部分发给AI并联翻译。将翻译内容替换
